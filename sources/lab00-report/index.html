MATLAB & ADALM-Pluto

Receive output documented

Install the hardware support package, select the network-connected receiver, and display its baseband spectrum.

Setup and method

MATLAB requires Communications Toolbox, DSP System Toolbox, and the ADALM-Pluto hardware support package. The toolbox list is checked using ver; the support package is installed through Add-Ons. For the network workflow, the USB-oriented setup step is deferred with Set up later, and RadioID specifies the IIO network URI.

The receive reference uses an antenna on RX1, a 945 MHz center frequency, 2.6 MS/s sampling, manual gain of 20 dB, and 4,096 samples per frame. No transmit operation is needed for this receive test.

MATLAB · reference receiver script
rx = sdrrx('Pluto', ...
    'RadioID', 'ip:192.168.1.10', ...
    'CenterFrequency', 945e6, ...
    'BasebandSampleRate', 2.6e6, ...
    'GainSource', 'Manual', ...
    'Gain', 20, ...
    'SamplesPerFrame', 4096, ...
    'OutputDataType', 'double');
info(rx)
sa = spectrumAnalyzer('SampleRate', 2.6e6);
for k = 1:200
    sa(rx());
end
release(rx);

sdrrx constructs the receiver, info(rx) requests device information, and rx() returns a sample frame. The Spectrum Analyzer displays the frame, and release(rx) releases the receiver resources after the loop.

Reference code and recorded run. The handout loop uses 200 iterations. The actual analyzer capture shows Updates = 800; the screenshot counter is reported independently of the reference loop.

Reading the spectrum

At 2.6 MS/s, the two-sided baseband window extends approximately from −1.3 to +1.3 MHz. Baseband zero is relative to the receiver's center frequency:

fRF = fc + fBB

If the reference center of 945 MHz was applied, the display corresponds approximately to 943.7–946.3 MHz. The central trace is around −36 dBm on the analyzer's displayed scale and falls toward the edges. The screenshot alone does not clearly resolve individual approximately 200 kHz GSM carriers or establish the signal's protocol.

Receive script

The configured center frequency is 945 MHz, the sample rate is 2.6 MS/s, RF bandwidth is 2 MHz, receive gain is manually set to 20 dB, and the buffer contains 4,096 samples.

Python · acquisition and FFT
import adi, numpy as np, matplotlib.pyplot as plt

sdr = adi.Pluto("ip:192.168.1.10")
sdr.sample_rate = int(2.6e6)
sdr.rx_lo = int(945e6)
sdr.rx_rf_bandwidth = int(2e6)
sdr.gain_control_mode_chan0 = "manual"
sdr.rx_hardwaregain_chan0 = 20
sdr.rx_buffer_size = 4096

x = sdr.rx()
print("samples:", x.shape, "sample_rate:", sdr.sample_rate)
X = np.fft.fftshift(np.fft.fft(x * np.hanning(len(x))))
f = (sdr.rx_lo + np.fft.fftshift(
    np.fft.fftfreq(len(x), 1/sdr.sample_rate))) / 1e6
plt.plot(f, 20*np.log10(np.abs(X) + 1e-9))
plt.xlabel("frequency (MHz)")
plt.ylabel("dB")
plt.grid(True)
plt.show()

Successful construction of the receiver, sample acquisition, and spectrum plotting document operation of pyadi-iio and the receive chain in the selected environment. The first row of Table 9 records this installation and execution check rather than assigning an unobserved package version number.

The processing chain acquires I/Q samples, applies a Hann window, calculates the FFT, shifts the frequency bins, and places the horizontal axis around 945 MHz. Its two-sided span is approximately 943.7–946.3 MHz.

The center of the displayed spectrum is higher than its edges. The vertical quantity is 20 log10(|X|) in dB relative to the numerical FFT magnitude. Determining absolute RF input power in dBm requires calibration; identifying modulation or individual GSM carriers requires additional analysis beyond this single-frame image.
