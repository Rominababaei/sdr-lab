# آزمایشگاه SDR — پیش‌گزارش آزمایش اول

نسخهٔ آماده برای GitHub Pages، شامل تمام محتوای سایت و فایل‌های دانلودی، با چیدمان فارسی و راست‌به‌چپ.

## محتویات

- `index.html`، `styles.css` و `app.js`: صفحه، طراحی و رفتارهای سایت.
- `content.json`: مسیر تصویر و فلوگراف.
- `downloads/lab01_monitor.png`: تصویر اصلی محیط GNU Radio.
- `downloads/lab01_monitor.grc`: فایل قابل ویرایش فلوگراف.
- `downloads/sdrlab_iq_recorder.py`: کد پایتون بلوک ضبط.
- `downloads/lab01_prereport_files.zip`: بستهٔ دانلود سه فایل تحویل.
- `fonts/`: فونت‌های Vazirmatn و مجوز SIL Open Font License.
- `.nojekyll`: نمایش مستقیم فایل‌های ایستا در GitHub Pages.
- `SHA256SUMS.txt`: فهرست هش فایل‌ها برای بررسی صحت نسخهٔ انتقال.

فایل‌های اصلی سایت بدون تغییر کپی شده‌اند. این سایت هیچ وابستگی اجرایی به دامنهٔ قبلی ندارد و به نصب بسته یا مرحلهٔ build نیاز ندارد. کد پایتون برای نمایش و دانلود ارائه می‌شود؛ اجرای آزمایش در محیط GNU Radio انجام می‌شود.

## انتشار در GitHub Pages

1. در حساب GitHub یک مخزن **Public**، مثلاً به نام `sdr-lab`، بسازید. برای نگه‌داشتن آن جدا از سایت شخصی، از مخزن مستقلی استفاده کنید.
2. تمام **محتویات این پوشه** را در ریشهٔ مخزن قرار دهید؛ `index.html` باید در ریشه باشد و ساختار پوشه‌های `downloads` و `fonts` حفظ شود.
3. در مخزن به **Settings → Pages** بروید.
4. در **Build and deployment → Source** گزینهٔ **Deploy from a branch** را انتخاب کنید.
5. شاخهٔ **main** و مسیر **/(root)** را انتخاب و **Save** کنید.
6. پس از تکمیل انتشار، نشانی سایت در همان صفحه نشان داده می‌شود. نشانی معمول چنین است: `https://USERNAME.github.io/sdr-lab/`.

راهنمای رسمی: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## بررسی پس از انتشار

- تصویر فلوگراف و فونت فارسی باید بارگذاری شوند.
- هر چهار لینک دانلود، شامل بستهٔ ZIP، باید قابل دریافت باشند.
- بخش کد پایتون باید متن فایل را نمایش دهد.
- دکمهٔ کپی کد و پیوندهای جابه‌جایی داخل صفحه را بررسی کنید.

برای مشاهدهٔ محلی نیز می‌توان از یک سرور ایستای معمول استفاده کرد؛ بازکردن مستقیم `index.html` با `file://` ممکن است بارگذاری کد با `fetch` را در مرورگر مسدود کند.
